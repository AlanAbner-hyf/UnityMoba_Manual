## 本阶段要得到什么

在 Test Runner 中，让整数位置的英雄从 (-35000, 0) 移动到 (-33000, 0)，并验证空输入会保留移动意图、错误帧不会修改世界。整个过程不需要场景。

前置条件：阶段 00 的 Core 与 EditMode 测试程序集已建立。本章给出可组合使用的最小 Core 文件；它暂时允许单位重叠，不含战斗和碰撞。

## 1. 先固定数据契约

- 平面使用 X/Z；1000 逻辑单位 = 1 Unity 世界单位。
- 20 个逻辑帧 = 1 秒；速度 200 表示每帧最多 200 个逻辑单位，约 4 世界单位/秒。
- 玩家英雄 ID 为 1、2；机器人为 3、4；塔为 5、6；奇数蓝方、偶数红方；小兵从 7 开始。
- 指令帧从 1 开始，初态 Frame 为 0。Step 只接受 Frame + 1。
- NoOp 表示这帧没有新命令，不表示停止。停止移动使用 MoveTo(当前位置)。

所有新文件先放在 `Assets/Moba/Runtime/Core/`。每完成一组相关文件就回 Unity 看 Console。

## 2. 创建整数坐标和数学函数

先创建下列两个**完整文件**。读 MoveTowards 时注意：距离平方用 long，中间乘法先提升类型，整数除法统一向零截断。不要先在 float 中计算再转 int。

```csharp
// 完整文件：Assets/Moba/Runtime/Core/Int2.cs
using System;

namespace Moba.Core
{
    public readonly struct Int2 : IEquatable<Int2>
    {
        public readonly int X;
        public readonly int Z;
        public Int2(int x, int z) { X = x; Z = z; }
        public bool Equals(Int2 other) => X == other.X && Z == other.Z;
        public override bool Equals(object obj) => obj is Int2 other && Equals(other);
        public override int GetHashCode() { unchecked { return (X * 397) ^ Z; } }
        public static bool operator ==(Int2 a, Int2 b) => a.Equals(b);
        public static bool operator !=(Int2 a, Int2 b) => !a.Equals(b);
        public override string ToString() => "(" + X + "," + Z + ")";
    }
}
```

```csharp
// 完整文件：Assets/Moba/Runtime/Core/IntegerMath.cs
using System;

namespace Moba.Core
{
    public static class IntegerMath
    {
        public static long DistanceSquared(Int2 a, Int2 b)
        {
            long x = (long)a.X - b.X, z = (long)a.Z - b.Z;
            return checked(x * x + z * z);
        }

        public static long SqrtCeiling(long value)
        {
            if (value < 0) throw new ArgumentOutOfRangeException(nameof(value));
            long low = 0, high = Math.Min(value, 3037000499L), floor = 0;
            while (low <= high)
            {
                long mid = low + (high - low) / 2;
                if (mid * mid <= value) { floor = mid; low = mid + 1; }
                else high = mid - 1;
            }
            return floor * floor == value ? floor : floor + 1;
        }

        public static bool WithinRange(Int2 a, Int2 b, int radius)
        {
            if (radius < 0) throw new ArgumentOutOfRangeException(nameof(radius));
            return DistanceSquared(a, b) <= (long)radius * radius;
        }

        public static Int2 MoveTowards(Int2 current, Int2 target, int step)
        {
            if (step <= 0) throw new ArgumentOutOfRangeException(nameof(step));
            long square = DistanceSquared(current, target);
            if (square <= (long)step * step) return target;
            long distance = SqrtCeiling(square);
            // C# integer division truncates toward zero, including negative directions.
            long x = ((long)target.X - current.X) * step / distance;
            long z = ((long)target.Z - current.Z) * step / distance;
            return new Int2(checked((int)(current.X + x)), checked((int)(current.Z + z)));
        }
    }
}
```

为什么距离使用向上取整的平方根：这样方向分量截断后，移动不会超过指定步长。零距离在平方根前已返回目标。这里的输入范围由 BattleConfig 限制，不把这些函数当作任意无限范围整数几何库。

## 3. 创建最小 BattleConfig

以下是阶段 01 的**完整文件** `BattleConfig.cs`。后续章节会扩展同一个类，不另建同名版本。

```csharp
using System;

namespace Moba.Core
{
    public enum SimulationMode : byte
    {
        MovementFixture = 0, CombatFixture = 1, Match = 2
    }

    public sealed class BattleConfig
    {
        public const string RulesVersion = "manual-movement-1";
        public const uint DefaultSeed = 0x6D2B79F5;
        public const int LogicHz = 20;
        public readonly int ConfigVersion = 1;
        public readonly int MinX = -40000, MaxX = 40000;
        public readonly int MinZ = -10000, MaxZ = 10000;
        public readonly Int2 BlueSpawn = new Int2(-35000, 0);
        public readonly Int2 RedSpawn = new Int2(35000, 0);
        public readonly Int2 BlueTower = new Int2(-25000, 0);
        public readonly Int2 RedTower = new Int2(25000, 0);
        public readonly int HeroHp = 1000, TowerHp = 6000;
        public readonly int HeroSpeed;
        public readonly SimulationMode Mode;

        public BattleConfig(int heroSpeed = 200,
            SimulationMode mode = SimulationMode.MovementFixture)
        {
            if (heroSpeed < 2 || heroSpeed > 1000 ||
                mode > SimulationMode.Match)
                throw new ArgumentException("Invalid config");
            HeroSpeed = heroSpeed;
            Mode = mode;
        }

        public static BattleConfig CreateDemo()
            => new BattleConfig(mode: SimulationMode.Match);

        public bool Contains(Int2 p)
            => p.X >= MinX && p.X <= MaxX &&
               p.Z >= MinZ && p.Z <= MaxZ;
    }
}
```

规则版本用 manual 前缀，避免学习中间版误连接到原项目服务端。此时 Match 枚举只预留位置，尚无兵线功能。

## 4. 创建命令类型

以下**完整文件**包含四种命令的数据格式，但本章世界只执行 NoOp、MoveTo。ActorCommand 表示某个机器人命令；FrameCommands 是服务器以后会广播的一帧输入集合。

```csharp
// 完整文件：Assets/Moba/Runtime/Core/CombatCommand.cs
using System;
using System.Collections.Generic;

namespace Moba.Core
{
    public enum CommandKind : byte { NoOp = 0, MoveTo = 1, Attack = 2, CastArea = 3 }

    public readonly struct CombatCommand : IEquatable<CombatCommand>
    {
        public readonly CommandKind Kind;
        public readonly Int2 Point;
        public readonly uint TargetId;
        public CombatCommand(CommandKind kind, Int2 point = default, uint targetId = 0)
        { Kind = kind; Point = point; TargetId = targetId; }
        public static CombatCommand NoOp => default;
        public static CombatCommand MoveTo(Int2 point) => new CombatCommand(CommandKind.MoveTo, point);
        public bool Equals(CombatCommand other) => Kind == other.Kind && Point == other.Point && TargetId == other.TargetId;
        public override bool Equals(object obj) => obj is CombatCommand other && Equals(other);
        public override int GetHashCode() { unchecked { return ((int)Kind * 397 ^ Point.GetHashCode()) * 397 ^ (int)TargetId; } }

        public void Validate(BattleConfig config)
        {
            if ((byte)Kind > (byte)CommandKind.CastArea) throw new ArgumentException("Unknown command.");
            if (Kind == CommandKind.MoveTo)
            {
                if (!config.Contains(Point) || TargetId != 0) throw new ArgumentException("Invalid move parameters.");
            }
            else if (Point != default || (Kind == CommandKind.Attack ? TargetId == 0 : TargetId != 0))
                throw new ArgumentException("Invalid command parameters.");
        }
    }

    public readonly struct ActorCommand
    {
        public readonly uint ActorId;
        public readonly CombatCommand Command;
        public ActorCommand(uint actorId, CombatCommand command) { ActorId = actorId; Command = command; }
    }

    public sealed class FrameCommands
    {
        public int FrameId { get; }
        public CombatCommand BluePlayer { get; }
        public CombatCommand RedPlayer { get; }
        public IReadOnlyList<ActorCommand> Robots { get; }
        public FrameCommands(int frameId, CombatCommand bluePlayer, CombatCommand redPlayer, params ActorCommand[] robots)
        {
            if (frameId < 1) throw new ArgumentOutOfRangeException(nameof(frameId));
            if (robots == null || robots.Length > 2) throw new ArgumentException("At most two robot inputs.");
            var copy = (ActorCommand[])robots.Clone();
            Array.Sort(copy, (a, b) => a.ActorId.CompareTo(b.ActorId));
            for (int i = 0; i < copy.Length; i++)
                if ((copy[i].ActorId != 3 && copy[i].ActorId != 4) || (i > 0 && copy[i - 1].ActorId == copy[i].ActorId))
                    throw new ArgumentException("Robot actor must be 3 or 4 and unique.");
            FrameId = frameId; BluePlayer = bluePlayer; RedPlayer = redPlayer;
            Robots = Array.AsReadOnly(copy);
        }
    }
}
```

重点读 Validate 和 FrameCommands 构造器：边界检查、参数规范化、机器人数量与 ID 限制在写入世界前完成。数组复制和排序避免外部在排队后悄悄改变帧内容。

## 5. 创建逻辑状态

创建以下**完整文件** `WorldState.cs`。为了让阶段 03—06 延续同一数据结构，提前保留战斗字段；此时不会全部使用。

```csharp
using System.Collections.Generic;

namespace Moba.Core
{
    public enum Team : byte { Blue, Red }
    public enum EntityKind : byte { PlayerHero, RobotHero, Tower, Minion }
    public enum FsmState : byte { Idle, Moving, AttackWindup, Dead }
    public enum MatchResult : byte { None, BlueWins, RedWins, Draw }

    public sealed class EntityState
    {
        public uint EntityId { get; internal set; }
        public EntityKind Kind { get; internal set; }
        public Team Team { get; internal set; }
        public Int2 Position { get; internal set; }
        public int Hp { get; internal set; }
        public FsmState State { get; internal set; }
        public CombatCommand Intent { get; internal set; }
        public int AttackReadyFrame { get; internal set; }
        public int HitFrame { get; internal set; }
        public int SkillReadyFrame { get; internal set; }
        public int RespawnFrame { get; internal set; }
        public int LastDamagedFrame { get; internal set; } = -1;
        public int PathIndex { get; internal set; }
        public bool Alive => Hp > 0;
        public bool IsHero => Kind == EntityKind.PlayerHero ||
                              Kind == EntityKind.RobotHero;
    }

    public sealed class WorldState
    {
        public int Frame { get; internal set; }
        public uint NextEntityId { get; internal set; }
        public uint RandomState { get; internal set; }
        public MatchResult Result { get; internal set; }
        public int NextWaveFrame { get; internal set; } = 1;
        public int WaveNumber { get; internal set; }
        public IReadOnlyList<EntityState> Entities { get; }
        internal WorldState(List<EntityState> entities)
        {
            Entities = entities.AsReadOnly();
        }
    }
}
```

`internal set` 使表现程序集只能读状态。FSM 和战斗仍在 Core 内部，因此能写。这里没有 Transform，也没有网络连接字段。

## 6. 创建最小 CombatWorld

创建以下**完整文件** `CombatWorld.cs`。声明为 partial 是为了阶段 04 把兵线规则拆到同一个类的另一个文件。

```csharp
using System;
using System.Collections.Generic;

namespace Moba.Core
{
    public sealed partial class CombatWorld
    {
        private readonly List<EntityState> entities = new List<EntityState>();
        public BattleConfig Config { get; }
        public WorldState State { get; }

        private CombatWorld(BattleConfig config, uint seed)
        {
            Config = config ?? throw new ArgumentNullException(nameof(config));
            if (seed == 0) throw new ArgumentOutOfRangeException(nameof(seed));
            for (uint id = 1; id <= 6; id++)
            {
                bool blue = (id & 1) == 1;
                bool tower = id >= 5;
                entities.Add(new EntityState
                {
                    EntityId = id,
                    Kind = tower ? EntityKind.Tower :
                        id >= 3 ? EntityKind.RobotHero : EntityKind.PlayerHero,
                    Team = blue ? Team.Blue : Team.Red,
                    Position = tower
                        ? (blue ? config.BlueTower : config.RedTower)
                        : (blue ? config.BlueSpawn : config.RedSpawn),
                    Hp = tower ? config.TowerHp : config.HeroHp,
                    Intent = CombatCommand.NoOp,
                    State = FsmState.Idle
                });
            }
            State = new WorldState(entities)
            {
                NextEntityId = 7, RandomState = seed
            };
        }

        public static CombatWorld Create(BattleConfig config,
            uint seed = BattleConfig.DefaultSeed) => new CombatWorld(config, seed);

        public EntityState FindEntity(uint id)
        {
            foreach (var e in entities)
                if (e.EntityId == id) return e;
            return null;
        }

        private void ValidateMovement(CombatCommand command)
        {
            command.Validate(Config);
            if (command.Kind != CommandKind.NoOp &&
                command.Kind != CommandKind.MoveTo)
                throw new NotSupportedException("Movement stage only");
        }

        private void ApplyMovement(EntityState entity, CombatCommand command)
        {
            if (!entity.Alive || command.Kind == CommandKind.NoOp) return;
            entity.Intent = command;
            entity.State = FsmState.Moving;
        }

        public void Step(FrameCommands commands)
        {
            if (commands == null) throw new ArgumentNullException(nameof(commands));
            if (State.Frame == int.MaxValue ||
                commands.FrameId != State.Frame + 1)
                throw new ArgumentException("Non-contiguous frame");
            ValidateMovement(commands.BluePlayer);
            ValidateMovement(commands.RedPlayer);
            foreach (var robot in commands.Robots) ValidateMovement(robot.Command);

            ApplyMovement(FindEntity(1), commands.BluePlayer);
            ApplyMovement(FindEntity(2), commands.RedPlayer);
            foreach (var robot in commands.Robots)
                ApplyMovement(FindEntity(robot.ActorId), robot.Command);

            foreach (var entity in entities)
            {
                if (!entity.Alive || !entity.IsHero ||
                    entity.Intent.Kind != CommandKind.MoveTo) continue;
                entity.Position = IntegerMath.MoveTowards(
                    entity.Position, entity.Intent.Point, Config.HeroSpeed);
                if (entity.Position == entity.Intent.Point)
                {
                    entity.Intent = CombatCommand.NoOp;
                    entity.State = FsmState.Idle;
                }
            }
            State.Frame = commands.FrameId;
        }
    }
}
```

依次看调用顺序：验证全部命令 → 更新意图 → 按固定实体顺序移动 → 提交帧号。错误输入在验证阶段抛出，不能先移动玩家一，再发现玩家二非法。

## 7. 编写可执行的 EditMode 测试

创建 `Assets/Moba/Tests/EditMode/DeterministicMovementTests.cs`，以下为**完整测试文件**：

```csharp
using System;
using Moba.Core;
using NUnit.Framework;

public sealed class DeterministicMovementTests
{
    [Test]
    public void NoOpKeepsIntentAndArrivalStops()
    {
        var world = CombatWorld.Create(new BattleConfig());
        var destination = new Int2(-33000, 0);
        for (int f = 1; f <= 20; f++)
            world.Step(new FrameCommands(f,
                f == 1 ? CombatCommand.MoveTo(destination) : CombatCommand.NoOp,
                CombatCommand.NoOp));
        Assert.That(world.FindEntity(1).Position, Is.EqualTo(destination));
        Assert.That(world.FindEntity(1).State, Is.EqualTo(FsmState.Idle));
        Assert.That(world.State.Frame, Is.EqualTo(20));
    }

    [Test]
    public void InvalidFrameDoesNotChangeState()
    {
        var world = CombatWorld.Create(new BattleConfig());
        var before = world.FindEntity(1).Position;
        Assert.Throws<ArgumentException>(() => world.Step(
            new FrameCommands(2, CombatCommand.NoOp, CombatCommand.NoOp)));
        Assert.That(world.State.Frame, Is.Zero);
        Assert.That(world.FindEntity(1).Position, Is.EqualTo(before));
    }

    [Test]
    public void DiagonalStepDoesNotExceedSpeed()
    {
        var from = new Int2(0, 0);
        var to = IntegerMath.MoveTowards(from, new Int2(-999, 777), 200);
        Assert.That(IntegerMath.DistanceSquared(from, to), Is.LessThanOrEqualTo(40000));
        Assert.That(to.X, Is.LessThan(0));
        Assert.That(to.Z, Is.GreaterThan(0));
    }
}
```

## 8. 常见问题与定位

| 现象                            | 原因与操作                                                        |
| ------------------------------- | ----------------------------------------------------------------- |
| 只移动一帧就停                  | 把 NoOp 写成清除 Intent；恢复“没有新输入保留原意图”             |
| 负方向比正方向不同              | 混用了四舍五入和整数除法；统一 IntegerMath                        |
| 斜向速度更快                    | 每轴都移动完整 step；应按整数距离归一化                           |
| 测试不能改 Position             | internal 是正确保护；当前测试不需要直接改，阶段 03 会说明测试友元 |
| 已写 final CombatWorld 编译失败 | 它引用 Collision、Lane 等未来模块；恢复本章最小版逐步扩展         |

参考核对：[整数算法](../../UnityMOBA/Assets/Moba/Runtime/Core/IntegerMath.cs)、[命令模型](../../UnityMOBA/Assets/Moba/Runtime/Core/CombatCommand.cs)。此时不要整文件覆盖为原项目最终 CombatWorld。
