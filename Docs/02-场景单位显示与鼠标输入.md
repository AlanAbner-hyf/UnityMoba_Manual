## 2. 建立 MobaDemo 场景和地图

1. 创建新场景并保存为 `Assets/Moba/Scenes/MobaDemo.unity`。
2. 创建 Cube，命名 Arena，Position = (0,-0.3,0)，Scale = (84,0.5,24)。地面顶面略低于逻辑平面 y=0。
3. 再创建 Cube，命名 Lane，Position = (0,-0.02,0)，Scale = (80,0.04,5)。
4. 两个 Cylinder 标记出生区，分别位于 (-35,0.025,0)、(35,0.025,0)，Scale = (6,0.015,6)。
5. 新建几个 URP/Lit 材质，给地面深色、兵线灰蓝色、出生区红蓝色。
6. 移除地图装饰的 Collider；地面拾取使用数学平面，不需要地面参与 Physics。保留单位拾取 Collider。
7. 保留一个 Directional Light。Camera 先用 Orthographic，Size = 31，Position = (0,60,-38)，Rotation 约 (58,0,0)，Far = 200，Tag = MainCamera。

不要给英雄 Rigidbody 或 NavMeshAgent；本章没有物理移动。

## 3. 编写 EntityView

在 Presentation 创建以下**完整文件** `EntityView.cs`：

```csharp
using Moba.Core;
using UnityEngine;

namespace Moba.Presentation
{
    public sealed class EntityView : MonoBehaviour
    {
        public Renderer Body;
        public uint EntityId => Entity.EntityId;
        public EntityState Entity { get; private set; }
        private Vector3 from, to;
        private bool initialized;
        private MaterialPropertyBlock colors;

        public void Snapshot(EntityState entity)
        {
            Entity = entity;
            var point = new Vector3(entity.Position.X / 1000f, 0,
                                    entity.Position.Z / 1000f);
            from = initialized ? to : point;
            to = point;
            initialized = true;
            if (Body != null)
            {
                // Create native-backed Unity objects during runtime, not field initialization.
                if (colors == null) colors = new MaterialPropertyBlock();
                colors.SetColor("_BaseColor",
                    entity.Team == Team.Blue ? Color.cyan : Color.red);
                Body.SetPropertyBlock(colors);
                Body.enabled = entity.Alive;
            }
            foreach (var collider in GetComponentsInChildren<Collider>())
                collider.enabled = entity.Alive;
        }

        public void Render(float alpha)
        {
            transform.position = Vector3.Lerp(from, to, Mathf.Clamp01(alpha));
        }
    }
}
```

这里把插值端点复制为 Vector3，而不是保存“上一帧 EntityState 引用”。EntityState 是可变对象，两个引用可能始终指向同一份最新状态。

`MaterialPropertyBlock` 会创建 Unity 原生对象，不能在 MonoBehaviour 的构造函数或实例字段初始化器中 `new`。本例只声明 `colors` 字段，在运行时由主线程调用 `Snapshot`、首次需要设置颜色时创建，之后重复使用。这样不会在拖拽挂载组件或反序列化时触发 `CreateImpl is not allowed` 错误，也不依赖对象的 `Awake` 是否已经执行。

## 4. 创建四种单位 Prefab

1. Hierarchy 创建空对象 HeroView，Transform 保持原点、旋转零、Scale 为 1。
2. 为它增加子对象 Capsule，命名 Body，Local Position = (0,1,0)；保留 CapsuleCollider，给 URP/Lit 材质。
3. 根对象挂 EntityView，把 Body 的 Renderer 拖到 Body 槽。
4. 把根对象拖入 `Assets/Moba/Prefabs`，生成 HeroView.prefab，再删除场景中的临时实例。
5. 以相同方式创建 RobotHeroView；可以先用 Cube 区分机器人。
6. MinionView 使用较小 Capsule，子模型中心 y=0.6；TowerView 用 Cylinder，子模型中心 y=2，Scale=(2.5,2,2.5)。
7. **根对象不要整体缩放**。模型大小放在子对象，逻辑位置与拾取查找仍从根对象计算。

同队玩家和机器人初始位置相同，现在可能互相遮挡。可以暂时只观察 ID 1/2；不要把模型偏移写回逻辑状态。阶段 12 解决逻辑出生占位。

## 5. 编写 BattleView

创建以下**完整文件** `BattleView.cs`：

```csharp
using System.Collections.Generic;
using Moba.Core;
using UnityEngine;

namespace Moba.Presentation
{
    public sealed class BattleView : MonoBehaviour
    {
        public Camera BattleCamera;
        public EntityView HeroPrefab, RobotHeroPrefab, MinionPrefab, TowerPrefab;
        public uint SelectedId = 1;
        private readonly Dictionary<uint, EntityView> views = new Dictionary<uint, EntityView>();
        private CombatWorld world;
        private float age;

        public static Vector3 Logical(Int2 point)
            => new Vector3(point.X / 1000f, 0, point.Z / 1000f);

        public bool TryGetEntityView(uint id, out EntityView view)
            => views.TryGetValue(id, out view);

        public void Bind(CombatWorld value)
        {
            foreach (var item in views.Values) Destroy(item.gameObject);
            views.Clear();
            world = value;
            if (world != null) Refresh();
        }

        public void Refresh()
        {
            if (world == null) return;
            var present = new HashSet<uint>();
            foreach (var entity in world.State.Entities)
            {
                present.Add(entity.EntityId);
                if (!views.TryGetValue(entity.EntityId, out var view))
                {
                    var prefab = entity.Kind == EntityKind.Tower ? TowerPrefab :
                        entity.Kind == EntityKind.Minion ? MinionPrefab :
                        entity.Kind == EntityKind.RobotHero ? RobotHeroPrefab : HeroPrefab;
                    view = Instantiate(prefab, transform);
                    views.Add(entity.EntityId, view);
                }
                view.Snapshot(entity);
            }
            var removed = new List<uint>();
            foreach (var pair in views)
                if (!present.Contains(pair.Key)) removed.Add(pair.Key);
            foreach (var id in removed)
            {
                Destroy(views[id].gameObject);
                views.Remove(id);
            }
            age = 0;
        }

        private void LateUpdate()
        {
            age = Mathf.Min(age + Time.unscaledDeltaTime, 1f / BattleConfig.LogicHz);
            float alpha = age * BattleConfig.LogicHz;
            foreach (var view in views.Values) view.Render(alpha);
        }
    }
}
```

本地世界每前进一步调用 Refresh；渲染帧只做插值。之后接网络时，Refresh 改为在收到并执行完整帧后调用。暂时每次 Refresh 的临时集合以清楚为先，后续再复用缓冲区。

## 6. 创建输入资产

在 `Assets/Moba/Input` 创建 Input Actions，命名 MobaInputActions。打开编辑器，创建 Action Map `Moba`：

| Action | Action Type | Control Type | Binding |
| --- | --- | --- | --- |
| Point | Value | Vector2 | <Mouse>/position |
| Order | Button | Button | <Mouse>/rightButton |
| Select | Button | Button | <Mouse>/leftButton |
| Skill | Button | Button | <Keyboard>/q |

保存资产。代码使用 Action 名称，不需要生成 C# 包装类。Action 必须 Enable 才会响应；参见 [Input System Actions](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.20/manual/Actions.html)。

创建以下**完整文件** `PlayerCommandInput.cs`：

```csharp
using Moba.Core;
using UnityEngine;
using UnityEngine.InputSystem;

namespace Moba.Presentation
{
    public sealed class PlayerCommandInput : MonoBehaviour
    {
        public InputActionAsset ActionsAsset;
        public BattleView View;
        public bool EnableCombat;
        public CombatWorld World { get; set; }
        public uint ControlledId { get; set; } = 1;
        public bool CanControl { get; set; } = true;
        private InputActionAsset actions;
        private InputAction point, order, select, skill;
        private CombatCommand pending;
        private bool pendingSkill;

        private void Awake()
        {
            actions = Instantiate(ActionsAsset);
            point = actions.FindAction("Moba/Point", true);
            order = actions.FindAction("Moba/Order", true);
            select = actions.FindAction("Moba/Select", true);
            skill = actions.FindAction("Moba/Skill", true);
            actions.Enable();
        }

        private void Update()
        {
            if (World == null || View == null || View.BattleCamera == null) return;
            Vector2 mouse = point.ReadValue<Vector2>();
            if (CanControl && EnableCombat && skill.WasPressedThisFrame())
                pendingSkill = true;
            if (!View.BattleCamera.pixelRect.Contains(mouse)) return;
            if (!order.WasPressedThisFrame() && !select.WasPressedThisFrame()) return;
            var ray = View.BattleCamera.ScreenPointToRay(mouse);
            EntityView picked = Physics.Raycast(ray, out var hit, 250)
                ? hit.collider.GetComponentInParent<EntityView>() : null;
            if (select.WasPressedThisFrame() && picked != null)
                View.SelectedId = picked.EntityId;
            if (!CanControl || !order.WasPressedThisFrame()) return;
            var actor = World.FindEntity(ControlledId);
            if (actor == null || !actor.Alive) return;
            if (EnableCombat && picked != null && picked.Entity.Alive &&
                picked.Entity.Team != actor.Team)
                pending = new CombatCommand(CommandKind.Attack, default, picked.EntityId);
            else if (new Plane(Vector3.up, Vector3.zero).Raycast(ray, out float distance))
            {
                Vector3 p = ray.GetPoint(distance);
                pending = CombatCommand.MoveTo(new Int2(
                    Mathf.Clamp(Mathf.RoundToInt(p.x * 1000), World.Config.MinX, World.Config.MaxX),
                    Mathf.Clamp(Mathf.RoundToInt(p.z * 1000), World.Config.MinZ, World.Config.MaxZ)));
            }
        }

        public CombatCommand Sample()
        {
            if (!CanControl) { ClearPending(); return CombatCommand.NoOp; }
            var result = pendingSkill ? new CombatCommand(CommandKind.CastArea) : pending;
            ClearPending();
            return result;
        }

        public void ClearPending() { pending = default; pendingSkill = false; }
        private void OnDestroy()
        {
            if (actions == null) return;
            actions.Disable();
            Destroy(actions);
        }
    }
}
```

本章没有覆盖地图的 UI。阶段 09 加 HUD 后需要划分相机 viewport 或加入 UI 命中排除；不能因为这个最小版能点击地图，就宣称 UI 防穿透已经完成。

## 7. 建立配置资产和本地驱动

在 Bootstrap 创建以下两个**完整文件**，分别保存：

这里的模式字段使用完整名称 `Moba.Core.SimulationMode`，因为 `UnityEngine` 也定义了同名类型；同时导入两个命名空间时，直接写 `SimulationMode` 会产生 CS0104 名称歧义错误。

```csharp
// BattleConfigAsset.cs
using Moba.Core;
using UnityEngine;
namespace Moba.Bootstrap
{
    [CreateAssetMenu(menuName = "Moba/Battle Config")]
    public sealed class BattleConfigAsset : ScriptableObject
    {
        public int HeroSpeed = 200;
        public uint Seed = BattleConfig.DefaultSeed;
        public Moba.Core.SimulationMode Mode = Moba.Core.SimulationMode.MovementFixture;
        public BattleConfig ToConfig() => new BattleConfig(heroSpeed: HeroSpeed, mode: Mode);
    }
}
```

```csharp
// ManualLocalBootstrap.cs
using Moba.Core;
using Moba.Presentation;
using UnityEngine;
namespace Moba.Bootstrap
{
    public sealed class ManualLocalBootstrap : MonoBehaviour
    {
        public BattleConfigAsset Configuration;
        public BattleView View;
        public PlayerCommandInput Input;
        public CombatWorld World { get; private set; }
        private double accumulator;
        private void Start()
        {
            World = CombatWorld.Create(Configuration.ToConfig(), Configuration.Seed);
            View.Bind(World);
            Input.World = World;
            Input.ControlledId = 1;
        }
        private void Update()
        {
            if (World == null || World.State.Result != MatchResult.None) return;
            accumulator += Time.unscaledDeltaTime;
            const double period = 1.0 / BattleConfig.LogicHz;
            int budget = 8;
            while (accumulator >= period && budget-- > 0)
            {
                int frame = World.State.Frame + 1;
                World.Step(new FrameCommands(frame, Input.Sample(), CombatCommand.NoOp));
                View.Refresh();
                accumulator -= period;
                if (World.State.Result != MatchResult.None) break;
            }
        }
    }
}
```

这是学习用本地积累器，不是后续缺输入等待时的网络调度器。网络版阶段 06/08 会使用 FrameScheduler，并避免等待结束后追赶全部墙钟欠帧。

## 8. 把组件接到场景中

1. 在 Config 右键 Create → Moba → Battle Config，命名 BattleConfig，Mode 保持 MovementFixture。
2. 创建 ClientPresentation 空对象，添加 BattleView 和 PlayerCommandInput。
3. 把相机拖到 BattleCamera；四个 Prefab 拖到对应槽；Input 的 ActionsAsset 绑定业务输入资产，View 指向同对象的 BattleView；EnableCombat 不勾选。
4. 创建 Bootstrap 空对象，挂 ManualLocalBootstrap，绑定 Configuration、View、Input。
5. 保存场景，再进入 Play Mode。不要同时保留多个 MainCamera 或多个 Bootstrap。

## 9. 按顺序验证

| 操作 | 应观察到的结果 |
| --- | --- |
| 进入 Play Mode，不点击 | 初始实体显示，逻辑 Frame 持续推进 |
| 右键地图 | 蓝方玩家移动，机器人不接受玩家输入 |
| 放开鼠标 | 英雄继续走向目标，不只移动一帧 |
| 左键敌方 | 只改变 SelectedId，不改变 ControlledId |
| 点击地图边缘外 | 量化目标受地图边界限制 |
| 改变 Game 窗口尺寸 | 拾取仍基于当前 Camera.pixelRect |
| 退出再播放 | 不出现重复输入回调或重复角色 |

如果角色贴地中心不对，调整模型子对象的 y，不调整实体根对象逻辑换算。如果运行报 MissingReference，逐个检查四个 Prefab 槽与 Body Renderer。鼠标无响应先检查 Game 窗口焦点、ActionsAsset 和 Action Map 名称。
